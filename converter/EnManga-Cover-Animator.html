Put it in the series folder as cover.gif (next to the volumes), then press △ → Rescan library in EnManga.

How it keeps the file small

All frames share one colour palette, and each frame only stores the area that changed since the previous one. Frames that don't change at all are merged into the one before. Shine and Sparkle only touch a small part of the picture, so they give the smallest files. Breathe, Drift, Sway and Glow move every pixel and make larger files.

Character only moves the parts you mark, so it also makes small files.

On the Vita each frame is held in memory at full size, and EnManga only animates a GIF whose frames fit in about 32 MB. The memory figure above tells you whether yours will play.
