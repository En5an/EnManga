# EnManga documentation

EnManga is a manga and comic reader for the PS Vita, made for collections stored on the console. These pages cover every feature in **Beta v1.0**.

| Page | What it covers |
|---|---|
| [1. Getting started](getting-started.md) | Installing, where to put your manga, supported files, folder layouts, series covers, file names |
| [2. Library](library.md) | The Library and History tabs, layouts, sorting and filters, search, categories, series actions |
| [3. Series screen](series.md) | Continue, the volume grid, volume preview, views and sorting inside a series, read marks, bookmarks |
| [4. Reader](reader.md) | Reading modes, scale and fit options, spreads, wide pages, cropping, zoom, appearance, tap zones, the reader menu, auto-scroll |
| [5. Reader presets](presets.md) | Built-in and custom presets, per-series and default settings, choosing a preset on first open |
| [6. Portrait mode, auto-rotate and rear touchpad](orientation.md) | Screen orientation, the rotation lock, reader orientation, the rear touchpad |
| [7. Controls](controls.md) | Every button and touch gesture, screen by screen |
| [8. Settings reference](settings.md) | Every setting, with its options and default |
| [9. EnManga Converter](converter.md) | Converting WebP manga to JPG on your computer |
| [10. Troubleshooting and FAQ](troubleshooting.md) | Common problems, the log file, data folder, resetting |
| [11. Cover Animator](cover-animator.md) | Turn a still cover into a small animated `cover.gif` |

Screenshots live in [`screenshots/`](screenshots/). The [screenshot checklist](screenshots/README.md) says which image goes where and how to capture them on the Vita.
