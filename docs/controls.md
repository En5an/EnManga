# 7. Controls

[← Documentation](README.md)

**Confirm** and **back** follow your Vita's system setting (○ or ✕). You can change this under Settings → *Confirm button*. Below, "confirm" and "back" mean whichever button that is.

In portrait the D-pad and sticks are remapped, so ↑ is always up on the screen.

## Library tab

| Button | Action |
|---|---|
| D-pad | Move between covers |
| ← at the left edge | Go to the tab rail (in portrait: ↓ from the last row goes to the tab bar) |
| Confirm | Open the series (or continue reading, if *Opening a series* is set to that) |
| START | Resume the selected series |
| SELECT | Series actions |
| □ | Search |
| △ | Library options (layout, sort, filter, categories, folders, rescan) |
| L / R | Previous / next category |
| Back | Clear the search |
| Touch | Tap a cover to open it · drag to scroll · tap a category name · tap the clock to lock or unlock rotation |

## Tab rail / tab bar

| Button | Action |
|---|---|
| ↑ / ↓ (← / → in portrait) | Choose Library / History / Settings |
| Confirm or → (↑ in portrait) | Go back into the tab's content |

## History tab

| Button | Action |
|---|---|
| ↑ / ↓ | Move |
| Confirm / START | Resume at the saved page |
| SELECT | Open the series screen |
| □ | Remove the entry |
| △ | Clear all history |

## Settings tab

| Button | Action |
|---|---|
| ↑ / ↓ | Move |
| ← / → | Change a choice or slider |
| Confirm | Toggle a switch, or open an item |
| Back | Return to the tab rail |

## Series screen

| Button | Action |
|---|---|
| D-pad | Move (← from the first column selects Continue) |
| L / R | Jump two rows |
| Confirm | Continue, or open the selected volume |
| START | Continue reading |
| □ | Mark the volume read or unread |
| SELECT | Volume menu |
| △ | Series menu (view, sort, filter, bookmarks, categories, presets, statistics) |
| Back | Back to the library |
| Touch | Tap a volume to open it · tap Continue · tap ← to go back · drag to scroll |

## Reader: paged modes

| Button | Action |
|---|---|
| ← / → | Previous / next page in the reading direction (scrolls a zoomed page first) |
| ↑ / ↓ | Scroll the page up or down; turns the page at the edge |
| L / R | Previous / next page, straight away |
| Left stick | Pan |
| Right stick ↑ / ↓ | Zoom |
| □ | Cycle the scale type |
| SELECT | Cycle this series' orientation |
| START | Reader settings |
| △ / confirm | Reader menu |
| Back | Close the reader |
| Touch | Tap zones · swipe to turn · pinch to zoom · double-tap to zoom · drag to pan · slide up / down on the right edge for brightness |
| Rear touchpad | Tap = next page · drag = pan or swipe |

## Reader: webtoon and long strip

| Button | Action |
|---|---|
| ↑ / ↓ | Scroll by the scroll step |
| ← / → | Scroll by almost a full screen |
| L / R | Scroll forward / back |
| Left stick | Scroll (and pan sideways when zoomed) |
| Right stick ↑ / ↓ | Zoom |
| □ | Auto-scroll on/off. While it's on, ↑/↓/←/→ change the speed. |
| Touch | Drag to scroll (with momentum) · pinch / double-tap to zoom · tap zones · slide up / down on the right edge for brightness |
| Rear touchpad | Tap = scroll on · drag = scroll |

## Reader menu (open)

| Button | Action |
|---|---|
| ← / → | Move the page slider (hold to go faster) |
| L / R | Previous / next chapter |
| SELECT | Bookmark this page |
| □ | This chapter's bookmarks |
| START | Reader settings |
| △ / confirm / back | Close the menu |
| Touch | Top bar: back · 🔒 rotation lock · 🔖 bookmark · ⚙ settings. Bottom: ‹ Prev / Next › chapter, slider, quick buttons (mode · scale or auto-scroll · orientation). |

## Colour picker (Settings → Accent colour → Custom colour…)

| Button | Action |
|---|---|
| D-pad / left stick | Move in the colour square |
| L / R, right stick | Change the hue |
| □ | Type a hex code |
| △ | Reset to the starting colour |
| Confirm / START | Save |
| Back | Cancel |
| Touch | Drag in the square or the hue bar; tap *Save* or ← |

## Lists and sheets (menus that slide in from the right)

| Button | Action |
|---|---|
| ↑ / ↓ | Move |
| ← / → | Change a choice or slider |
| Confirm | Select / toggle |
| Back | Close |

## Folder browser (Settings → Folders → Add folder)

| Button | Action |
|---|---|
| ↑ / ↓ | Move |
| Confirm / → | Open folder |
| ← / back | Up one level |
| △ / START | Use the current folder |
