# Screenshot checklist

Every image in the documentation is a **placeholder** until you replace it. To swap one in, save your screenshot over the placeholder **with exactly the same file name**. The docs pick it up automatically, with no text to edit.

## Taking screenshots on the Vita

1. Turn screenshots on: Vita **Settings → System → Enable Screenshot**.
2. In EnManga, hold the **PS button** and press **START**. The Vita saves a 960×544 image.
3. The images are saved in `ux0:picture/SCREENSHOT/`, in a folder per app. Copy them to your PC with VitaShell (USB or FTP).
4. **Portrait screenshots** are saved sideways (landscape). Rotate them upright before using them:
   - **D-pad down:** rotate 90° counter-clockwise.
   - **D-pad up:** rotate 90° clockwise.

Tips:
- Use real manga you own, but avoid showing a whole page of copyrighted art in large images. Library and series screens with covers are fine for most projects.
- Use PNG for crisp UI. If a file name below ends in `.png`, keep it `.png`.
- To refresh a screenshot later, just overwrite the same file.
